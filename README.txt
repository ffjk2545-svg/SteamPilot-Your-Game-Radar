STEAMPILOT v2.1 — Your Game Radar
=================================

เว็บช่วยค้นหาและคัดเกมจาก Steam Store พร้อมรายละเอียดเกมแบบป๊อปอัป, Backlog,
Price Watch, ตัวกรองละเอียด และลิงก์ไปยัง SteamDB สำหรับตรวจสอบประวัติราคา

วิธีเปิดดูหน้าตา
----------------
1. แตกไฟล์ ZIP ให้อยู่ในโฟลเดอร์เดียวกัน
2. เปิด index.html ด้วย Chrome / Edge ได้ทันที
3. หากเปิดเป็นไฟล์โดยตรง การค้นหาสดอาจถูกเบราว์เซอร์บล็อกด้วย CORS
   ในกรณีนั้นให้ใช้ปุ่ม “เปิดผลลัพธ์เต็มบน Steam” หรือเปิดโปรเจกต์ผ่าน Vercel

วิธี deploy ให้ค้นหาสดทำงานได้เสถียร (แนะนำ)
----------------------------------------------
โปรเจกต์มี Vercel Serverless Functions ไว้ในโฟลเดอร์ /api เพื่อเรียก Steam Store จากฝั่งเซิร์ฟเวอร์
1. อัปโหลดโฟลเดอร์โปรเจกต์ทั้งหมด รวมโฟลเดอร์ api ไปที่ GitHub repository
2. นำ repository เข้า Vercel แล้ว deploy ตามปกติ (ไม่ต้องตั้ง build command สำหรับไฟล์ static)
3. เปิด URL ของ Vercel แล้วลองค้นหาเกม เช่น elden ring, persona, cozy, survival
4. API ที่ใช้: /api/steam-search และ /api/steam-details

หากใช้ GitHub Pages/Static hosting อย่างเดียว โฟลเดอร์ /api จะไม่ถูกรันเป็น serverless function
หน้าเว็บยังมีปุ่มเปิดค้นหาบน Steam เป็นทางสำรอง แต่รายละเอียดสดภายในป๊อปอัปอาจโหลดไม่ได้

ความสามารถ v2.1
----------------
- ค้นหาสดจาก Steam Store ผ่าน serverless endpoint และโหลดผลลัพธ์เพิ่มครั้งละ 50 รายการ
- ปุ่มเปิดผลลัพธ์เต็มบน Steam สำรองไว้เสมอ เพื่อเข้าถึงดัชนีค้นหาของ Steam โดยตรง
- ป๊อปอัปรายละเอียดเกม: ภาพ Header, วันวางจำหน่าย, ราคา, Metacritic (ถ้ามี), จำนวนคำแนะนำ,
  ผู้พัฒนา, ผู้จัดจำหน่าย, ประเภท/หมวดการเล่น, แพลตฟอร์ม, ภาษา และคำอธิบาย
- ตัวกรองละเอียด: รูปแบบผู้เล่น, คะแนน Metacritic, สถานะวันวางจำหน่าย และระบบปฏิบัติการ
- ปุ่มเพิ่มเข้ากองดอง / เฝ้าราคา และบันทึกรายการใน localStorage ของเบราว์เซอร์
- ภาพปกใช้ Steam CDN พร้อมภาพสำรองเมื่อโหลดไม่สำเร็จ
- SteamPilot ไม่พึ่งการ scrape/crawl SteamDB; ใช้ Steam Store เป็นข้อมูลค้นหา และลิงก์ไป SteamDB สำหรับราคา/สถิติเพิ่มเติม

ข้อจำกัดที่ควรรู้
-----------------
- Steam Store อาจมีข้อจำกัดการเข้าถึงหรือเปลี่ยนรูปแบบคำตอบได้; หากผลค้นหาไม่โหลด ให้ใช้ลิงก์ผลลัพธ์เต็มบน Steam
- ราคาและรายละเอียดควรตรวจสอบที่หน้าเกมจริงก่อนซื้อ โดยเฉพาะราคาแต่ละภูมิภาค/ช่วงลดราคา
- ข้อมูลที่บันทึกด้วย localStorage อยู่ในเบราว์เซอร์และอุปกรณ์นั้น ไม่ซิงก์ข้ามเครื่อง
- ปฏิทินเทศกาลเป็นข้อมูลกำหนดการตั้งต้น ควรเช็กกำหนดการล่าสุดจาก Steamworks/SteamDB
- โปรเจกต์อิสระ ไม่ได้เป็นส่วนหนึ่งหรือได้รับการรับรองจาก Valve, Steam หรือ SteamDB
