STEAMPILOT v2.0 — Your Game Radar
=================================

เว็บช่วยตัดสินใจสำหรับคนเล่น Steam: หาเกมที่ตรงอารมณ์, จัดการเกมที่ยังไม่ได้เล่น,
เก็บเกมที่อยากรอส่วนลด, ติดตามเกมออกใหม่ และวางแผนช่วงเทศกาลลดราคา

เริ่มต้นใช้งาน
--------------
1. แตกไฟล์ ZIP ทั้งหมดไว้ในโฟลเดอร์เดียวกัน
2. เปิด index.html ด้วย Chrome, Edge หรือ Firefox รุ่นใหม่
3. ใช้เมนูด้านซ้ายสลับหน้าต่าง ๆ
4. กดหัวใจบนการ์ดเพื่อเก็บเข้า Price Watch
5. กด “กองดอง” เพื่อเก็บเกมไว้สุ่มเลือกเล่น
6. กด “เพิ่มเกมของฉัน” เพื่อเพิ่มเกมอื่น ๆ โดยใส่ชื่อและ Steam App ID (ถ้ามี)
7. ข้อมูลรายการส่วนตัวบันทึกใน localStorage ของเบราว์เซอร์เครื่องนั้น

สิ่งที่มีใน v2.0
----------------
- ดีไซน์ Dark Neon พร้อม responsive layout สำหรับมือถือและเดสก์ท็อป
- ภาพปกเกมจาก Steam CDN ในการ์ดเกมและส่วน Hero พร้อม fallback เมื่อรูปโหลดไม่ได้
- แคตตาล็อกตัวอย่าง 20+ เกมเพื่อทดลองค้นหา
- ค้นหาชื่อเกมและกรองตามอารมณ์ เวลา แนวเกม และช่วงงบตัวอย่าง
- Backlog, Price Watch, เพิ่ม/ลบเกม และบันทึกข้อมูลในเบราว์เซอร์
- สุ่มเลือกเกมจากกองดองพร้อมหน้าต่างแนะนำ
- ปฏิทิน Steam events ที่ประกาศแล้วและสถานะผ่านไปแล้ว/กำลังจัด/กำลังจะมา
- ลิงก์ไปยัง Steam Store และ SteamDB สำหรับการตรวจสอบราคา/ข้อมูลเพิ่มเติม

ข้อจำกัดที่ควรรู้
-----------------
- นี่คือ prototype ฝั่งหน้าเว็บ ข้อมูลในแคตตาล็อกและค่าช่วงงบเป็นข้อมูลตั้งต้น ไม่ใช่ราคาเรียลไทม์
  ให้กดเปิด Steam Store เพื่อตรวจราคาจริงก่อนซื้อ
- ภาพปกโหลดผ่านอินเทอร์เน็ตจาก Steam CDN หากออฟไลน์หรือ URL ของภาพเปลี่ยน ระบบจะแสดง
  พื้นหลังสำรองแทนภาพ ไม่ควรนำภาพของเกมไปใส่ในไฟล์ ZIP โดยไม่ตรวจสอบสิทธิ์การใช้งาน
- SteamDB ไม่มี API สาธารณะให้เว็บทั่วไปนำมาใช้โดยตรง และระบุว่าไม่อนุญาตให้ scrape/crawl
  ดังนั้นเว็บนี้ใช้ลิงก์ไป SteamDB แทนการดึงข้อมูลจาก SteamDB โดยอัตโนมัติ
- ปฏิทินเป็นข้อมูลกำหนดการที่ประกาศไว้ ณ เวลาจัดทำ ควรตรวจสอบกับแหล่งทางการอีกครั้งเมื่อถึงช่วงงาน
- localStorage อยู่ในเบราว์เซอร์เครื่องปัจจุบัน ไม่ซิงก์ข้ามอุปกรณ์ และการล้างข้อมูลเว็บไซต์จะลบรายการ
